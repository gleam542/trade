連接本機 trade-signal API 的即時版本

ℹ 此頁面需要 本機執行的 API 伺服器 才能顯示資料：先 cd trade-signal && python main.py 抓資料，再 uvicorn api:app --reload --port 8000 啟動 API，最後直接用瀏覽器開啟這個檔案（或用任何靜態伺服器）。這個檔案不是透過 Claude Artifact 發布的頁面——那個版本連不到你本機的伺服器。
