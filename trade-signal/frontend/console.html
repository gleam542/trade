Signal Console

連接本機 trade-signal API 的即時版本

ℹ 此頁面需要 本機執行的 API 伺服器 才能顯示資料：先 cd trade-signal && python main.py 抓資料，再 uvicorn api:app --reload --port 8000 啟動 API，最後直接用瀏覽器開啟這個檔案（或用任何靜態伺服器）。這個檔案不是透過 Claude Artifact 發布的頁面——那個版本連不到你本機的伺服器。
⚠

策略試算

輸入本金與目標，按下「分析」呼叫 API 的 /api/advise 掃描全部追蹤中的交易對（現貨＋合約都算，同一個代號在兩邊各自算一個候選），挑出訊號分數最高者作為參考，下方圖表會跟著切換到建議的交易對——也不是保證達成的投資建議。（掃描範圍跟上方「市場別」選單選的是現貨還是合約無關，選單只影響「交易對」分頁要看哪一邊；每次分析都要重新掃描全部交易對，改了本金／盈利／小時數要再按一次「分析」才會套用新數字）
